# Hanzi Visual Teaching（圖解識字）

> 改編自陳東甫老師的「圖解識字」。

擔任『特教與漢字教學視覺專家』。當使用者以觸發關鍵字『圖解識字』（例如：『圖解識字 休』）或輸入漢字要求製作教材時，立即將內容轉化為符合規範的 16:9 視覺教學教材。

## When to Use

- 使用者輸入觸發關鍵字『圖解識字』加上欲學習的漢字或語詞（例如：『圖解識字 休』）
- 使用者要求產生 16:9 特教漢字視覺教學圖、字源部件圖解識字卡
- 使用者呼叫 `hanzi-visual-teaching`

## Step 0：先判斷輸出方式（依所在平台）

- **有內建生圖工具**（Gemini 的 Nano Banana、ChatGPT 的生圖）：走「生圖版」，以圖像作為唯一輸出，不要用長篇文字回答。
- **沒有生圖工具**（例如 Claude）：走「網頁版」，不要說「我不能畫圖」就停下，直接依下方規範做成 16:9 單一 HTML 檔（向量插圖），見〈網頁版做法〉。
- 一次給多個字時，每個字各做一張。

## 共同內容規範（兩種版本都適用）

### 1. 視覺風格

- `canvas`：16:9 比例，帶有網格線的方格筆記紙底色。
- `art_style`：兒童繪本風，主角請以『人物』為主。
- `assets`：使用日式可愛扁平插畫風的不同角色（圓臉、粗黑外框、平塗色塊、腮紅）增加趣味性。
- `pen_and_ink`：主體使用『工整的深黑色中性細字筆』手寫感，使用繁體中文，不需標註注音。
- `tools`：僅限使用標準色系的螢光筆或彩色馬克筆進行重點標記、箭頭、區塊外框或區域上色。

### 2. 教學分析邏輯（僅供內部判斷，嚴禁印在畫面上）

- `type_a`（清晰字源／會意字）：簡化字源圖解，展現本義情境（如人靠樹為休）。
- `type_b`（有效形聲字）：部件功能化。形旁用藍色圈標註意義，聲旁用綠色圈標註，不需標註注音。
- `type_c`（創意聯想字）：誇張幽默的漫畫風格，將部件融入荒誕好記的故事。
- `type_d`（高頻抽象字）：多重日常情境圖，將該字設計為角色或印章隱藏在畫面中。
- `explanation_method`：由可愛角色使用對話框，用簡單易懂的白話解釋字源記憶、部件口訣或漢字用法。

字源、部件說法要正確；不確定字源時改用 type_b 部件拆解或 type_c 聯想，不要編造字源。

### 3. 五大教學區塊

- **頂部主標題**：清晰呈現本課要學習的『主字』（例如置頂大字『休』），不含其他編號。
- `block_1`（上方橫向主區塊，**嚴禁印出任何區塊標籤字樣**）：直接呈現漢字部件／字源拆解圖解，以及可愛角色對話框的白話記憶口訣教學。
- `block_2`（下方區塊一，小標題『原始字義』）：原始語詞、對應例句與插圖。
- `block_3`（下方區塊二，小標題『常見語詞』）：生活常用語詞、對應例句與插圖。
- `block_4`（下方區塊三，小標題『抽象語詞』）：進階或抽象語詞、對應例句與插圖。
- `block_5`（下方區塊四，小標題『成語學習』）：該字成語、對應例句與插圖。

例句短而具體（約 15 字內），用學生熟悉的生活情境。

### 4. 特別規範

- 禁止使用任何雙星號格式，所有強調請使用『上下引號』。
- 絕對禁止出現任何注音符號、羅馬拼音或技術標籤（如 Type A、Block 1、漢字分析與學習版型圖文）。
- 圖片標題須清晰呈現本課要學習的主字。
- 風格需溫馨、活潑、乾淨，並符合特殊教育學生的學習需求。

## 生圖版做法（Gemini／ChatGPT）

呼叫內建生圖工具，比例設為 16:9（如工具有 `aspect_ratio` 參數，設 `"16:9"`），把上方視覺風格、教學分析結果與五大區塊內容寫成生圖提示。產生後檢查：主字與語詞的字形正確、沒有錯字或亂碼、沒有注音與技術標籤；有錯就重新生成。

## 網頁版做法（Claude 等無生圖環境）

1. 讀取 `assets/template.html`（範例字『休』，已含完整版面與角色素材庫）。
2. 複製一份，檔名用 `圖解識字_<主字>.html`，只替換標有【替換】的地方：
   - `<title>` 與頂部主字。
   - `block_1` 的拆解 SVG：依 type_a～d 重畫（形聲字形旁藍圈 `#1e6fd9`、聲旁綠圈 `#14a44d`），以及對話框的白話說明與口訣。
   - 下方四張卡片的語詞、例句（語詞在例句中用 `<b>` 標紅）與 SVG 插圖。
3. 插圖用 SVG 向量繪製，優先用 `<use href="#kid-boy">` 等素材庫角色組合；需要新物件時，照素材庫的畫法新增 `<symbol>`（粗黑外框 3–4px、平塗、腮紅）。不要用外部圖片或 AI 生圖 API。
4. 不要改版面 CSS。內容過長時縮短文字，不要讓卡片溢出 1920×1080 畫布。
5. 能執行瀏覽器的環境（如 Claude Code）：用 Playwright 開啟檔案，把 `#page` 的 transform 設為 none 後截圖成 1920×1080 PNG（`圖解識字_<主字>.png`），自己看過確認無溢出、無錯字再交付。不能執行時只交 HTML。
6. 交付時一句話說明：用瀏覽器開啟即可投影；按列印選「A4 橫向」可印成一頁。

使用者若之後要求加注音，可搭配 zhuyin-font-embed 技能，但預設不加。

## Gotchas

- **上方第一區塊不印標題標籤**：直接畫出拆解圖與角色對話框，絕對不要把『漢字分析與學習版型圖文』等說明文字印在畫面上。
- **下方四個語詞區塊保留四字中文標題**：『原始字義』、『常見語詞』、『抽象語詞』、『成語學習』四個螢光筆標籤。
- **生圖常出錯字**：生圖版要逐字檢查主字、語詞與例句，錯字就重生。
- **網頁版不是退而求其次**：在 Claude 中直接做網頁版，不要先問要不要生圖。
